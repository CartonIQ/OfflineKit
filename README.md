**OfflineKit** is a premium, 100% offline utility toolkit for Android. Built for speed, privacy, and reliability, it packs 12 advanced tools into a sleek Material 3 interface.

No accounts. No cloud. No tracking. Just pure, fast utilities when you need them.

---

## ✨ Features

*   🧮 **12 Advanced Tools:** Calculator, Unit Converter, Percentage, Date Difference, Age Calculator, Time Converter, Text Tools, QR Generator, Password Generator, Notes, Expense Tracker, and Storage Helper.
*   🔒 **100% Offline & Private:** All data (notes, expenses) is saved locally using Room DB. Nothing is sent to the cloud.
*   🎨 **Premium UI/UX:** Built with Jetpack Compose, featuring a near-black, white, and red aesthetic.
*   🛡️ **Secure:** Password generation uses a cryptographically secure random source.
*   💰 **Ad-Aware:** Optional AdMob banners that never block core functionality.

---

## 🛠️ Tech Stack

*   **Language:** Kotlin
*   **UI:** Jetpack Compose (Material 3)
*   **Local Database:** Room DB
*   **Navigation:** Compose Navigation
*   **Monetization:** Google AdMob & UMP Consent
*   **Architecture:** MVVM (Model-View-ViewModel)
